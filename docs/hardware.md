# Hardware

## Overview

This document describes the physical hardware used to host the homelab.

---

## Host System

| Component | Specification |
|-----------|---------------|
| Model | Dell OptiPlex 3020 MT |
| CPU | Intel Core i5-4590 |
| RAM | 8 GB DDR3 |
| Primary Storage | 120 GB SSD |
| Secondary Storage | 500 GB HDD |
| Network | Gigabit Ethernet |

---

## Purpose

The OptiPlex serves as the primary virtualization host running Proxmox VE.

Virtual machines and containers will be deployed on this system to provide networking, cybersecurity, and self-hosted services.
